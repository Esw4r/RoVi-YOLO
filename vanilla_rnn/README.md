# Gopher AI — CNN + vanilla RNN

This module is trained and integrated with the sibling `gopher-ui` project.
It is an **experimental teacher-distilled prototype**, not a validated road-damage detector.
The supplied MP4 recordings contain no human annotations. Targets were generated by
`YOLO/gopher-ai_v1.pt` at confidence 0.25 and have not been reviewed.

## Architecture and output

`BGR frame -> frozen YOLO11n backbone layer 10 -> global average pooling (256 features)
-> training-set normalization -> 8-frame vanilla tanh RNN (64 hidden units)
-> 5 independent sigmoid scores for the final frame`

This is `torch.nn.RNN`, not an LSTM or GRU. The backbone is reused without retraining;
only the RNN and classification head are trained. Frames are sampled at 5 FPS, so
eight frames span 1.4 seconds. Image inference uses square 512 letterboxing and FP32.
The backend captures CNN features during the same YOLO pass that produces the boxes.

The temporal scores do not add boxes, track individual potholes, alter YOLO confidence,
or suppress detections. A missing training class is shown as `Not trained`, never as
a confident negative. Scores are not calibrated probabilities of actual damage.

## Actual training data and limitations

Eight three-minute 640x480 recordings at 30 FPS were sampled into 7,200 frames.
No windows cross video files. The split was chosen after auditing teacher-label availability:

| Split | Recordings | Windows |
| --- | --- | ---: |
| Train | November 19, clips 000679F and 000682F | 1,786 |
| Validation | November 19, clip 000683F | 893 |
| Test | November 19, clip 000684F | 893 |
| Additional evening test (`night_test` in JSON) | All four November 10 clips | 3,572 |

Daytime splits are from the same drive. Adjacent clips and overlapping windows are
correlated; independent-route or independent-trip damage generalization is not established.
The supplied imagery includes dusk/evening traffic and daytime roads, not an annotated
road-damage benchmark.

Training positive sequence counts, in checkpoint class order:

| Class | Positive sequences |
| --- | ---: |
| Longitudinal crack | 30 |
| Transverse crack | 0 |
| Alligator crack | 2 |
| Other corruption | 3 |
| Pothole | 6 |

Multiple positive windows can describe one physical defect. These counts are not counts
of independent damage instances. The model has insufficient class coverage for reliable use.

## Recorded outcome

The RNN completed 20 epochs with early stopping; epoch 10 was selected using validation
macro F1, with weighted BCE as a tie-breaker. Test macro F1 against YOLO pseudo-labels is
**0.0645**; the same-feature final-frame linear baseline scored **0.0714**.
The RNN did not improve on this baseline. Additional evening-test macro F1 is 0.
These are teacher-agreement metrics, not independently measured damage accuracy.
No test-set positives exist for several classes, so their performance cannot be established.

An initial loss-selected run collapsed toward background predictions. It is preserved
under `artifacts/initial_run/`. The final run uses positive weights capped at 100 and
validation-F1 selection. No inference threshold was tuned on the test set (threshold 0.5).

## Reproduce

From the Gopher-AI root, using the existing Python environment:

```powershell
python -m vanilla_rnn.train
python -m unittest vanilla_rnn.test_temporal -v
```

The script expects the supplied eight MP4 files under `dashcam_recordings` and the CNN
under `YOLO`. Review the explicit split in `train.py` before changing the dataset.
Feature extraction uses CUDA when available; head training uses CPU with four threads.
Features are cached per video with source/CNN SHA-256 and preprocessing fingerprints.
Normalization uses only training frames. Each batch contains chronological windows,
although the order of windows is shuffled during training.

Outputs in `artifacts/`:

- `best.pt`: inference checkpoint, including preprocessing contract and class support.
- `metrics.json`: validation, test, evening test, and frame-baseline results.
- `manifest.json`: source provenance, splits, and pseudo-label counts.
- `rnn_history.json`, `frame_baseline_history.json`: training curves as numeric records.
- `features/`: cached CNN features, targets, and source timestamps.

After retraining, copy `artifacts/best.pt` and `artifacts/metrics.json` into
`gopher-ui/models/RNN/`, then restart the backend. Alternatively set
`GOPHER_RNN_CHECKPOINT` to the newly trained checkpoint.

Tested environment: Python 3.12.10, PyTorch 2.11.0+cu128, Ultralytics 8.4.90,
NVIDIA GTX 1650 (4 GB VRAM). Other dependencies: NumPy, OpenCV; backend: FastAPI,
Uvicorn, HTTPX for integration tests. No new dependencies were installed.

For useful retraining, collect/review damage labels with substantially more positive
examples and separate recording sessions per split. The current script deliberately
identifies its labels as unreviewed pseudo-labels; it does not imply human annotation.
